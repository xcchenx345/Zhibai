为什么叫知白

The Name
知其白，守其黑

名字出自《道德经》第二十八章："知其白，守其黑，为天下式。"

看得清明亮的一面，却安守于暗处的本色。这既是这套纯黑白界面的由来——去掉所有多余的色彩，只留墨与纸；也是一种使用态度：模型知道得再多，最终拿主意的仍然是人。

守黑，不是藏拙，是留白。

常见问题

FAQ
要用它需要准备什么？

一个小米账号，在小米开发者平台开通 MiMo API 获取 Key。填进应用设置即可，全程一分钟。

对话内容会经过别的服务器吗？

不会。API Key 只存在你的手机里，请求直连小米官方接口，应用本身不设中转、不收集数据。

支持哪些模型？以后新模型怎么办？

目前接入 MiMo V2.5 系列。启动时自动拉取官方模型列表，新模型上线后无需升级应用即可看到。

应用收费吗？

应用本身免费、开源。API 调用费用按小米官方定价，与本应用无关。

为什么现在还下载不了？

APK 打包与签名还在收尾。发布后此页的按钮会直接指向安装包。
